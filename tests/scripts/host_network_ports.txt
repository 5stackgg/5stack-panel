# The ports a workload may listen on from the host's network, checked by
# host_network_ports_test.sh against every overlay update.sh can apply:
#
#   <Kind/name> <port[-port]/protocol>[,...] <public|internal> <what for>
#
# public: open to the internet on purpose.
# internal: allowed on the host, but it must stay reachable from the cluster
# and the nodes' LAN or Tailscale only, never the internet.
#
# Any other port fails, unless the container binds it to a private hostIP, or
# it is MediaMTX's and every authInternalUsers entry only lets in private
# addresses.
